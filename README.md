# 🎮 Hangman Game
A simple and fun beginner-friendly Hangman game built with Python.

## ✨ Features
- 🎯 Random word selection
- 📚 Multiple categories
- 💡 Hint system
- ❤️ 6 lives
- 🏆 Score system
- 🔄 Play again option
- ❌ Prevents repeated guesses
- 🎨 ASCII Hangman graphics

## 📂 Categories
The game includes words from:
- 🐯 Animals
- 🍕 Food
- 🌍 Places
- 💻 Technology

## 🛠️ Technologies Used
- Python
- Random module

## ▶️ How to Run
1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python hangman.py
